# Format: CATEGORY<TAB>WEIGHT<TAB>TERM, one rule per line.
#
#   CATEGORY  a value of content.ReportCategory
#   WEIGHT    1 to 100, how sure the term alone makes the category. From 85 the
#             server refuses the text (when refusing is on); from 55 it can put
#             it before moderation (only when an administrator switched that on).
#             Keep 85 and above for terms with no innocent reading at all.
#   TERM      a word or a phrase. Matched on whole normalised words, never as a
#             part of a word, so "Analyse" is safe next to a rule for "anal".
#             Phrases win over the exceptions: "kill yourself" fires although
#             "kill" alone is a technical word.
#
# Before adding a term, ask whether it can appear in an ordinary work message,
# an issue, a log or a shell command ("I'll shoot you an email", "ich schlage
# dich vor", "cp video.mp4"). If it can, do not add it, or add it below 85.
