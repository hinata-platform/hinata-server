# English denylist — SEED LIST.
#
# Format:  CATEGORY <TAB> WEIGHT <TAB> TERM
#
#   CATEGORY  one of the ModerationCategory constants
#   WEIGHT    1-100 confidence that this term alone indicates the category.
#             >= 85 refuses content outright on a blocking surface (see
#             ModerationPolicy.DEFAULT_BLOCK_THRESHOLD); >= 55 queues it for a
#             human. Reserve >= 85 for terms with no innocent reading at all.
#   TERM      a single word or a phrase of up to three words. Matched on whole
#             normalised tokens only — never as a substring — so "assess" is
#             safe next to a rule for "ass".
#
# This list is deliberately small and conservative. It is a floor, not a
# solution: it exists so a self-hosted instance with no external provider still
# refuses the unambiguous cases, and so the pipeline has something real to test
# against. Broad coverage is the job of an external provider (see
# ModerationProperties.provider), which an operator can switch on.
#
# Before adding a term, ask whether it can appear in an ordinary defect report.
# If it can, either do not add it or add it at FLAG weight only.
