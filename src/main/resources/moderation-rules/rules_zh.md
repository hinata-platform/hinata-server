# {operator} 的社区规则

这里有很多人一起工作。为了顺利协作，以下规则适用于你在任务、评论、页面、文件和个人资料中撰写、上传或分享的一切内容。

对于违反这些规则的内容以及骚扰他人的人，我们零容忍。

## 1. 尊重

尊重每一个人，即使你们意见不同。批评针对事情，而不是针对人。

## 2. 不贬低他人

不辱骂、不霸凌、不骚扰。任何人都不应因出身、肤色、宗教、性别、性取向、残障、年龄或其他特征而受到贬低。

## 3. 不威胁，不使用暴力

不威胁他人，不煽动暴力，也不美化暴力，即使是暗示或“开玩笑”也不行。

## 4. 不发布色情内容，保护儿童

不发布性或色情内容。任何将儿童性化或危及儿童的内容一律禁止，没有例外。审核人员会将其删除，并可能报告给执法机关。

## 5. 尊重他人隐私

未经他人同意，不分享他人的私人数据，例如地址、电话号码、健康数据，或并非面向所有人的照片和消息。

## 6. 不发垃圾信息，不欺诈，不传播恶意软件

不发布无人请求的广告、连锁信、钓鱼信息，不欺骗他人，也不分享会造成损害的文件。

## 7. 法律与他人权利

遵守法律。只分享你有权分享的内容，尊重著作权、商标以及他人的其他权利。

## 举报

如果你看到违反这些规则的内容，请在应用中举报。明知虚假的举报本身也违反这些规则。

如有疑问，请通过 {contact} 联系 {operator} 的审核人员。
